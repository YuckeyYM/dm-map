# デジタルマーケティングの地図

デジタルマーケティングの全体像を、7つの層と2本の流れで頭に入れるための学習アプリ。

- 地図: 需要をつくる / 見つけられる / 受け止める / つなぎとめる / データ基盤 / 計測する / 守る の7層と、各層の道具30点
- 流れ: 客の流れ（認知→推奨）とデータの流れ（接触→学習）
- AIO: AI Optimization。生成AI検索での可視性を、事実だけで整理
- 用語: 会議で意味が取れないと止まる12語
- 数字: 電通「2025年 日本の広告費」とAI検索まわりの実測値
- クイズ: 全20問からランダム10問

単一ファイル (index.html)、外部依存なし。iPhone のホーム画面に追加して使う。

出典: 電通「2025年 日本の広告費」(2026-03-05)、Google 検索セントラル、OpenAI Bots ドキュメント、Similarweb / SparkToro (2026)。
